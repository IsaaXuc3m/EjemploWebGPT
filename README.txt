PLANTILLA WEB ESTATICA

Archivos:
- index.html: estructura y contenido.
- styles.css: diseño y adaptación a móviles.
- script.js: año automático del pie de página.
- assets/: carpeta para imágenes.

PUBLICAR EN GITHUB PAGES
1. Crea un repositorio nuevo en GitHub.
2. Descomprime esta carpeta y sube index.html, styles.css, script.js y assets/.
3. Abre Settings > Pages en el repositorio.
4. En Build and deployment, selecciona Deploy from a branch.
5. Elige la rama main y la carpeta /(root), y pulsa Save.
6. Espera a que GitHub Pages publique la web. La URL aparecerá en Settings > Pages.

Personaliza los textos y añade solo imágenes que tengas derecho a utilizar.
